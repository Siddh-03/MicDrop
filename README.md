# 🎤 MicDrop - Real-time Communication Platform

A modern full-stack communication platform built with TypeScript, featuring real-time messaging, and seamless user interactions.

## ✨ Features

- 💬 **Instant Messaging System**
- 👥 **Multi-user Support**
- 🔐 **Secure Authentication**
- 📱 **Responsive Design**
- ⚡ **Lightning-fast Performance**

## 🛠️ Technology Stack

### Frontend
- **TypeScript** - Type-safe JavaScript development
- **Modern Frontend Framework** - React/Vue/Angular
- **Real-time Communication** - WebRTC/Socket.IO
- **Responsive UI** - CSS3/SCSS

### Backend
- **Node.js** - Server-side JavaScript runtime
- **TypeScript** - Enhanced development experience
- **Real-time Events** - Socket.IO
- **Database** - MongoDB/PostgreSQL
- **Authentication** - JWT/OAuth

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn
- MongoDB (if using)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Siddh-03/MicDrop.git
   cd MicDrop
   ```

2. **Backend Setup**
   ```bash
   cd Backend
   npm install
   npm run dev
   ```

3. **Frontend Setup**
   ```bash
   cd Frontend
   npm install
   npm start
   ```
